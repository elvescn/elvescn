## 导入步骤

1. 下载 [Anki](https://apps.ankiweb.net/) — 免费，支持 Mac / Windows / iPhone / Android
2. 打开 Anki → 菜单 **文件 → 导入**
3. 选择 `.txt` 文件
4. 确认设置：
   - 分隔符：制表符 (Tab)
   - HTML 格式：✅ 开启
5. 点击导入，完成

## 建议开启 FSRS 算法

设置 → 牌组选项 → 调度算法 → 选 **FSRS**

这是中国研究者叶峻峣开发的记忆算法，比默认 SM2 效率高 40%，现已内置于 Anki 最新版。

## 卡片格式

**数学卡片正面**：`【三角函数】sin²α + cos²α = ?`
**数学卡片背面**：
- 公式答案（加粗）
- 原理解释
- 历年真题例子（最多2道，含解题过程）

**物理/化学卡片正面**：`【运动学】匀变速直线运动四大公式 ★★★`
**物理/化学卡片背面**：
- 核心知识点（黄色高亮关键词）
- **【考法】** 高考出题方式（蓝色）
- **【易错】** 常见错误（橙色）

## 建议学习节奏

| 阶段 | 操作 | 时间 |
|---|---|---|
| 启动期（第1-2周）| 每天 20 张新卡 | 约 20 分钟 |
| 稳定期 | 每天 10 张新卡 + 当日到期复习卡 | 约 15 分钟 |
| 考前两个月 | 停止新卡，只复习到期卡 | 约 10 分钟 |

**建议顺序**：先数学（公式最多）→ 再物理 → 最后化学
