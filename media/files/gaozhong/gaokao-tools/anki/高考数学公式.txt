<b>【三角函数】</b> ⭐<br><br>sin²α + cos²α = ?	<b style='font-size:1.1em'>sin²α + cos²α = 1</b><br><br>最基本的三角恒等式，由单位圆定义直接得出，是推导其他恒等式的基础。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2023全国甲卷文第13题</small><br>已知sinα+cosα=√2，求sinαcosα的值<br><i style='color:#2d7a2d'>由(sinα+cosα)²=1+2sinαcosα=2，得sinαcosα=1/2</i><br><small style='color:#888'>2018全国Ⅲ卷理第4题</small><br>若sinα=1/3，求cos2α的值<br><i style='color:#2d7a2d'>cos2α=1−2sin²α=1−2×(1/9)=7/9</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>tanα 用 sinα 和 cosα 怎么表示？	<b style='font-size:1.1em'>tanα = sinα / cosα</b><br><br>正切的定义式，cosα≠0时成立。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2022新高考I卷第6题</small><br>已知sin(α+β)+cos(α+β)=2√2cos(α+π/4)sinβ，求tanα<br><i style='color:#2d7a2d'>利用tanα=sinα/cosα，化简等式得tanα=1</i><br><small style='color:#888'>2015全国Ⅰ卷理第2题</small><br>sin20°cos10°−cos160°sin10°的值<br><i style='color:#2d7a2d'>利用tanα=sinα/cosα及诱导公式，原式=sin20°cos10°+cos20°sin10°=sin30°=1/2</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>sin(α+β) 的展开公式？	<b style='font-size:1.1em'>sin(α+β) = sinα·cosβ + cosα·sinβ</b><br><br>和角正弦公式，高考最常考的展开公式之一，必须正背倒背。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2020全国Ⅰ卷理第9题</small><br>已知α∈(0,π)，且3cos2α−8cosα=5，求sinα<br><i style='color:#2d7a2d'>由3(2cos²α−1)−8cosα=5，得cosα=−2/3，sinα=√5/3</i><br><small style='color:#888'>2019全国Ⅱ卷理第10题</small><br>已知α∈(0,π/2)，2sin2α=cos2α+1，求sinα<br><i style='color:#2d7a2d'>由4sinαcosα=2cos²α，得tanα=1/2，sinα=√5/5</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>cos(α+β) 的展开公式？	<b style='font-size:1.1em'>cos(α+β) = cosα·cosβ − sinα·sinβ</b><br><br>和角余弦公式，注意是减号。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2023全国乙卷理第6题</small><br>已知cos(α+β)=1/3，cosαcosβ=1/6，求cos(α−β)<br><i style='color:#2d7a2d'>cos(α−β)=2cosαcosβ−cos(α+β)=2×(1/6)−1/3=0</i><br><small style='color:#888'>2016全国Ⅲ卷文第6题</small><br>若tanθ=−1/3，求cos2θ<br><i style='color:#2d7a2d'>cos2θ=(1−tan²θ)/(1+tan²θ)=(1−1/9)/(1+1/9)=4/5</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>sin2α = ？（二倍角公式）	<b style='font-size:1.1em'>sin2α = 2sinα·cosα</b><br><br>正弦二倍角，常用于化简含sinα·cosα的乘积。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2021新高考I卷第6题</small><br>若tanθ=−2，求sin2θ+cos2θ的值<br><i style='color:#2d7a2d'>sin2θ=2tanθ/(1+tan²θ)=−4/5，cos2θ=(1−tan²θ)/(1+tan²θ)=−3/5，和为−7/5</i><br><small style='color:#888'>2017全国Ⅱ卷文第3题</small><br>函数f(x)=sin2x的最小正周期<br><i style='color:#2d7a2d'>由sin2x=2sinxcosx，周期T=2π/2=π</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>cos2α 有几种写法？	<b style='font-size:1.1em'>cos2α = cos²α−sin²α = 2cos²α−1 = 1−2sin²α</b><br><br>余弦二倍角三种形式，降幂公式由此推出。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2022全国甲卷理第11题</small><br>已知cos2α=3/5，求cos²α−sin²α的值<br><i style='color:#2d7a2d'>cos2α=cos²α−sin²α=3/5</i><br><small style='color:#888'>2018全国Ⅰ卷文第8题</small><br>已知cosα=3/5，求cos2α<br><i style='color:#2d7a2d'>cos2α=2cos²α−1=2×(9/25)−1=−7/25</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>tan(α+β) = ？	<b style='font-size:1.1em'>tan(α+β) = (tanα+tanβ) / (1−tanα·tanβ)</b><br><br>注意分母有个减号；tanα·tanβ≠1时成立。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2020全国Ⅱ卷理第2题</small><br>若tan(α+π/4)=1/7，求tanα<br><i style='color:#2d7a2d'>tan(α+π/4)=(tanα+1)/(1−tanα)=1/7，解得tanα=−3/4</i><br><small style='color:#888'>2015重庆理第9题</small><br>若tanα=2，tanβ=3，求tan(α+β)<br><i style='color:#2d7a2d'>tan(α+β)=(2+3)/(1−2×3)=5/(−5)=−1</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>正弦定理是什么？	<b style='font-size:1.1em'>a/sinA = b/sinB = c/sinC = 2R</b><br><br>2R是外接圆直径，常用于求边或角。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2023新高考I卷第17题</small><br>△ABC中，A=60°，a=2，求b+c的最大值<br><i style='color:#2d7a2d'>由a/sinA=2R，得2R=4/√3，b+c=2R(sinB+sinC)≤4</i><br><small style='color:#888'>2019全国Ⅰ卷理第17题</small><br>△ABC中，a=3，b=2，A=60°，求sinB<br><i style='color:#2d7a2d'>由a/sinA=b/sinB，得sinB=bsinA/a=2×(√3/2)/3=√3/3</i>	高考数学 三角函数
<b>【三角函数】</b> ⭐<br><br>余弦定理是什么？	<b style='font-size:1.1em'>a² = b² + c² − 2bc·cosA</b><br><br>推广的勾股定理，A=90°时退化为勾股定理。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2022新高考II卷第18题</small><br>△ABC中，a=2，b=3，C=60°，求c<br><i style='color:#2d7a2d'>c²=a²+b²−2abcosC=4+9−12×(1/2)=7，c=√7</i><br><small style='color:#888'>2017全国Ⅰ卷理第17题</small><br>△ABC中，a=2，b=3，cosA=1/3，求c<br><i style='color:#2d7a2d'>a²=b²+c²−2bccosA，4=9+c²−2c，解得c=5</i>	高考数学 三角函数
<b>【三角函数】</b><br><br>sin(π−α) = ？	<b style='font-size:1.1em'>sin(π−α) = sinα</b><br><br>口诀：奇变偶不变，符号看象限。π−α在第二象限，sin为正。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2021全国乙卷文第4题</small><br>sin(π−α)=1/3，求sinα<br><i style='color:#2d7a2d'>sin(π−α)=sinα=1/3</i><br><small style='color:#888'>2016全国Ⅱ卷理第9题</small><br>若sin(π−α)=3/5，求cos2α<br><i style='color:#2d7a2d'>sinα=3/5，cos2α=1−2×(9/25)=7/25</i>	高考数学 三角函数
<b>【三角函数】</b><br><br>sin(π+α) = ？	<b style='font-size:1.1em'>sin(π+α) = −sinα</b><br><br>π+α相当于对原点对称，sin变号。<br><br><b style='color:#555;font-size:.85em'>━ 历年真题 ━</b><br><small style='color:#888'>2020全国Ⅲ卷文第5题</small><br>sin(π+α)=−1/2，求sinα<br><i style='color:#2d7a2d'>sin(π+α)=−sinα=−1/2，sinα=1/2</i><br><small style='color:#888'>2018北京理第11题</small><br>sin(π+α)=−√3/2，α∈(0,π/2)，求tanα<br><i style='color:#2d7a2d'>−sinα=−√3/2，sinα=√3/2，tanα=√3</i>	高考数学 三角函数
