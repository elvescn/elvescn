## ✨ Features

- **Fully offline** — no internet needed after page load
- **No login, no tracking** — open and use immediately
- **Mobile optimized** — works on phones, tablets, and desktops
- **Progress saved locally** — browser localStorage, no server
- **Free forever** — all tools, all subjects

## 🚀 Usage

Clone or download, then open `index.html` in any browser. No server needed.

```bash
git clone https://github.com/daligao/gaokao-tools.git
cd gaokao-tools
open index.html   # macOS
# or just double-click index.html on Windows
```

> **Note**: The biology question bank (`shengwu/`) includes image-based questions. Images are served from the live demo site. For fully local use with images, contact the author.
