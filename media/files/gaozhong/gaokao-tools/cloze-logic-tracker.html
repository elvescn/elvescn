完形考的是逻辑推理,不是翻译。点「提示」不给中文 — 只高亮信号词,让你像解推导题一样推出答案。
信号词扫描
🧭 怎么用 · 把完形当推导题做（点开）

1先通读全文,抓住故事的「情绪走向」和「事件因果」,不要急着逐空翻译。

2点空格选答案。底部弹出 A–D 四个选项,选你推出来的那个。

3卡住时点「💡 提示」。工具不会给中文翻译,而是把文中和这个空相关的逻辑信号词(however / because / not only…)或复现的同义词高亮出来,并告诉你这是哪一类逻辑(转折?因果?复现?)。你的任务:根据这些「已知条件」推出空格该填哪一类词,再回选项里找。

4想看全文有哪些逻辑路标,打开右上角「信号词扫描」,所有连接词会按颜色亮起。

5对答案后会按逻辑类型统计对错,并汇总近 7 天失分率 — 让你知道自己是栽在「转折」还是「复现」上,针对性补。某类逻辑连续 3 次以上失分,会被标红提醒为「逻辑盲区」。

6做真题时发现的高价值信号词,随手存进「🚩 我的路标库」。之后任何文章里出现它,都会自动加蓝色底标提醒你注意。数据保存在本机,可一键导出备份。
