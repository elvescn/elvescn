什么是 Project Euler？

projecteuler.net 是一个只有数学题的编程挑战网站，全球150万人在做。每道题都需要数学思维+编程来解决。

规则：用任何语言，找到答案，提交数字。对了就通过，不对继续想。

为什么做这个？高考数学考"会做题"，PE训练"能建模"——把问题变成代码的能力，是理科思维的核心。
